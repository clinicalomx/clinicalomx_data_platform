# Build app design contract

Which component each surface of the Build app gets, at what density, and how the state vocabulary is drawn.
Token values live in `tokens.css`. Do not retype one here.
The interface meets WCAG 2.2 AA.

## Files

| File | Copy to | What it is |
|---|---|---|
| `tokens.css` | `<reflex app>/assets/tokens.css` | `DESIGN.md` as CSS: vendored primitives, semantic tokens, component classes |
| `tokens.py` | `<reflex app>/design/tokens.py` | the Python names of the tokens, plus `THEME` and `STYLESHEETS` |
| `states.py` | `<reflex app>/design/states.py` | the state, verdict and kind vocabularies with their glyphs |
| `build_preview.py` | stays here | regenerates `preview.html` and the vendored palette in `tokens.css` |
| `preview.html` | stays here | every token and component, light and dark. Open it in a browser |

Nothing here imports Reflex, and no CI job runs it.
The copies are the live code.

## Wiring

If `tokens.css` is in the app's `assets/`:

```python
import reflex as rx
from .design import tokens

app = rx.App(
    theme=rx.theme(**tokens.THEME),
    stylesheets=tokens.STYLESHEETS,   # tokens.css must be LAST
    style=tokens.APP_STYLE,
)
```

If `tokens.css` ships inside a wheel instead, inline it in the head:

```python
app = rx.App(
    theme=rx.theme(**tokens.THEME),
    stylesheets=[tokens.FONT_STYLESHEET],
    head_components=[rx.el.style(tokens.tokens_css())],   # HEAD, not body
    style=tokens.APP_STYLE,
)
```

Do not pass a packaged file to `stylesheets=` or wrap it in `rx.asset`. The build fails.

The four layers, in order:

1. `tokens.css` section 1 vendors the colour primitives. It depends on nothing.
2. `tokens.css` sections 2 onward define semantic tokens and components in plain CSS.
3. `rx.theme(**THEME)` points Radix Themes at the same two scales.
4. A component uses `tokens.X` or a `cx-` class. Never a hex value.

The primitives are literal values, regenerated by `build_preview.py`. Never edit them by hand.
`tokens.STREAMLIT_THEME` is the Review app's half.

## The state vocabulary

`states.py` draws the states. `clinicalomx.extract.availability` defines what they mean.
`LADDER` is the order, `TINTED` is derived from it, and `why()` is the one import site for `_WHY`.
`DESIGN.md` holds the ladder table, The Quiet Default Rule and The No Green Rule.

1. **`-` is not a state.** Every MISSING column prints `main.MISSING_NOT_PROBED`. It means *nobody looked*.
   Render it as `.cx-notprobed` with `title="not probed - this app reads the catalogue only"`.
   Never as a chip, never as `0`.
2. **Kinds share their mark with the diagram.** Each `KindSpec.glyph` is the graphviz shape `diagram.KIND_SHAPE` gives that kind, and `KindSpec.dot_shape` records the pairing.
   If `KIND_SHAPE` changes, change `KINDS` in the same commit.
3. **An unclassifiable kind gets the dashed box.** Never a guessed icon.

## Components, surface by surface

The Reflex app is `packages/clinicalomx/src/clinicalomx/extract/app/web/`.

### Shell

- **Sidebar** (`.cx-panel` treatment, `SIDEBAR_W`, sticky, full height, `RULE_STRONG` right edge).
  In order: ROI picker, divider, the `index built {timestamp}` caption, `↻ Refresh from instance`, `rx.color_mode.button()`.
  Sections separate by a rule and a small-caps label.
- **ROI picker**: a type `.cx-select` over the instance's own ROI subtypes, a `.cx-input` searching by name, the ROI `.cx-select`, and a `.cx-caption` saying how many of how many are listed.
  The list is capped, and the caption reports the cap.
  The selected ROI is always listed, even when the filter excludes it.
  All three controls hold the user's input locally (`rx.debounce_input`).
- **No source toggle.** `render(live=True)` draws none.
- **Header**: `.cx-title` is the app name, once.
  The ROI is `.cx-section-head`, type in `TEXT_MUTED`, name in `TEXT_PRIMARY`.
- **Readouts** replace `st.metric`: `.cx-readout__label` above, `.cx-readout__value` below, two of them separated by `SPACE_6` and a vertical `RULE`. No box.
- **Tabs**: `.cx-tabs` / `.cx-tab`. Corpus, What is here, Build something, Jobs.

### Disclosure

`.cx-disclosure` replaces every expander.
A ruled header row with a square caret, then an indented body with a hairline spine.
No background change, no radius, no shadow, no border box.

- The head is a `<summary>` inside a `<details>`, at a 24px minimum height. The caret is decorative.
- `tokens.css` hides the native marker in both engines.
- A closed `<details>` does not print its body. Never put a caveat in a disclosure.

### Tables

`.cx-table` inside `.cx-table-scroll`.

| Table | Density | Footer needed |
|---|---|---|
| `_corpus_panel` coverage and recipes | `compact` | yes |
| `_element_panel` child elements | `compact` | yes |
| `_role_table` roles | `compact` | yes |
| `_stores_panel` variables and coords | `default` | no |
| `_layout_panel` pieces | `compact` | **yes**, it caps at 200 |
| `_jobs_panel` runs | `comfortable` | no |

- Column order: state chip (fixed width), identifiers in mono, numbers right-aligned and tabular, free text last.
- A long key uses `.cx-key--path`, which truncates at the **start**, with the full value in a `title`.
- Coverage cells use `.cx-coverage`: a 46px track, then the fraction as text. Never the bar alone.

### Element choice rows

The centre of the Build tab.
One `.cx-slot` per model slot, in the target model's own order (Images, Labels, Shapes, Tables, Points).
Each holds declared rows, then added rows, then `.cx-add`.

- **Slot head** (`.cx-slot__head`): kind glyph, label, `RULE_STRONG`, count right-aligned.
  The `SLOT_HELP` sentence sits under it as `.cx-caption`. It is not collapsible.
- **A declared row** is `.cx-row`, a three-column grid.
  The row's state is the state glyph before the element name. Never a coloured edge.
  - left: state glyph, element name in mono, the level it reads underneath, the coverage bar, any `unplaceable` warning
  - centre: the role select.
    An option reads as role, the variable after a middle dot, then what it fills or its state, as a WORD.
    The variable is on the option label.
    Use a native `<option>`, not a custom listbox. The glyph cannot go in an option; the word carries the meaning.
  - right: the `include` checkbox and, when included and required, `allow absent`
- **An excluded row stays visible** as `.cx-row--excluded`: 55% opacity, name struck through.
- **An added row** is the same grid with four columns, a ghost `✕`, and a `.cx-row__added-label` reading `added` in small caps.
- **`.cx-add`** is a dashed outline, not a filled button, disabled with its reason in `title`.

### Blueprint and diagrams

- Two DOT graphs side by side in one disclosure, open by default, each in `.cx-diagram`.
- The `group sources by` control is `.cx-segmented`.
- `diagram.legend()` goes under both, once, as `.cx-legend`, with the `states.py` glyphs in place of its emoji.

### Notices

`.cx-notice`, four severities:

- `--info`: `ℹ️` captions, layout notes
- `--ok`: `st.success`, the Plannable banner
- `--warn`: `st.warning`, every `⚠️` caveat, every layout absence
- `--blocked`: `st.error`, the BLOCKED banner, every submit failure

`av.caveats()`, `sv.caveats()`, `result.caveats()`, `relations.caveats()` and `tools.job_caveats()` return caveats the app must print.
Render them as `--warn` at `TEXT_MICRO`, at the foot of the surface they qualify. Never collapse them.

### Plan and layout

- Verdict banner: `--ok` "Plannable · N unit(s)" or `--blocked` "BLOCKED", with the token as a `.cx-key` and a copy control.
- Absences: one `--warn` notice each, phrased as an effect on the output, with the resolver's own word in parentheses.
- The reads caption ("N metadata read(s), batched... No pixel was read") is `.cx-caption` directly under the table. Keep it.
- OME-XML, the tree, the JSON and "How it resolved - the wiring" are each a closed disclosure.

### Jobs

- One disclosure per plan token. Summary: `{token} · N run(s) · M unit(s) · {tally}`, each state in the tally a small chip.
- "this session" is a word on the token, not a colour.
- `run states as of {timestamp}` is `.cx-caption` beside the refresh control. Never drop it.
- The empty state is one `.cx-caption` line, no illustration.

### Controls

- `.cx-btn` (secondary), `.cx-btn--primary` (**one per surface**, ink not accent), `.cx-btn--ghost` (the `✕`), `.cx-input`, `.cx-select`, `.cx-segmented`, `.cx-tab`, `.cx-check`.
- Checkbox square, radio circular. A toggle only for `Register outputs as Artifacts` and the colour mode.
- `.cx-check` is the checkbox and its label as one 24px target: the input sits inside the label, so the whole row toggles. The box itself is 16px.
- The submit button is the one loud element.
  When sizing fails it is disabled, with a `--blocked` notice above it saying why.
  The plan, the corpus and the layout preview still render.

## Density

| Density | `--cx-row-h` | Font | Use |
|---|---|---|---|
| `compact` | 24px | `TEXT_DENSE` | any table that can exceed ~30 rows |
| `default` | 26px | `TEXT_DENSE` | the general case |
| `comfortable` | 32px | `TEXT_BODY` | under ~15 rows |

Every long table gets all ten:

1. Sticky header.
2. Bounded scroll at `62vh`.
3. Tabular figures, globally.
4. Numbers right, text left, state column fixed width.
5. Full-row hover, not cell hover.
6. No zebra stripes.
7. A coverage bar beside every fraction, never instead of it.
8. A row count in the footer, always, and what was truncated.
9. Keys truncate at the start, full value in `title`.
10. Sort by severity where the app already does (`av.recipes` blocked-last, `child_coverage` by `-present`).

Not built: virtualisation, column resizing, a column chooser, per-column filters, pagination.
Add virtualisation first if a table ever exceeds a few thousand rows.

## Known gap: dark-mode diagrams

`clinicalomx.extract.app.diagram` emits DOT with light-mode hex baked in (`STATE_COLOUR`, `_UNREACHED`, the `#0969da` edges).
No CSS variable reaches them.

- `.cx-diagram` keeps a light ground in **both** modes. Do not use `filter: invert()`.
- The fix belongs in the `clinicalomx` wheel, not the Reflex app: `source_dot` and `object_dot` take a `palette` argument, and `STATE_COLOUR` becomes two dicts.
- `STATE_COLOUR` still gives `present` a green. When the palette argument lands, `present` and `ready` become ink.

## Checklist

A surface is done when all of these hold:

- [ ] No hex value in the component. Every colour is a `tokens.X` or a `cx-` class.
- [ ] No `border-radius` other than `RADIUS`, except a radio or the spinner.
- [ ] No `box-shadow` unless the thing floats and can be dismissed.
- [ ] No tinted left border on anything. Every `border-left` is a neutral grey rule, never an accent or a state colour.
- [ ] Every state is a glyph **and** its word, in every row.
- [ ] Every MISSING column prints `.cx-notprobed`, never `0` and never a chip.
- [ ] Every table that can truncate prints its row count and what was cut.
- [ ] Every caveat the layer returns is rendered as `--warn`, uncollapsed.
- [ ] The index timestamp and the run-states timestamp are both on screen.
- [ ] Focus visible on every control.
- [ ] Legible in greyscale.
- [ ] Legible at 120 rows.
